# 25 Days, 25 Flutter Screens 

A daily challenge building UI screens in Flutter — one screen a day for 25 days, focusing on clean code, reusable widgets, and single-responsibility structure.

Part of the **DEPI Flutter Developer Trainee** track.
Instructor: [Fady Sameh](https://www.linkedin.com/in/fadysameh/)

## Progress

| Day | Screen       | Highlights                                                      |
| --- | ------------ | --------------------------------------------------------------- |
| 1   | Profile Card | Used separate widget files and created reusable card components |
| 2 | Login Screen | Reusable `CustomButton` used across Log In / Google / Facebook |

## Tech Stack

* Flutter & Dart
* Google Fonts
* Font Awesome Flutter

## Structure

Each day/project lives in its own folder, with widgets separated into individual files under `widgets/`.
